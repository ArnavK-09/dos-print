# Agent notes

Dos Print is an Android application built with Kotlin and Jetpack Compose. The application module is `dos-print/`.

Keep the root `README.md` as the project entry point. Project guides live in this directory. Update their relative links when documents move.

Build from the repository root with `./build.sh assembleDebug`. The local toolchain, generated APKs, and NokoPrint reference artifacts are intentionally excluded from version control.
